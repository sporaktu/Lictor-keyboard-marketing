# Lictor

The website of the Lictor, a split, wireless, 40-key keyboard by Sporaktu.

It is plain files with nothing to build. To look at it, run
`python3 -m http.server` in this directory and open the address it prints.

keeps its own licence is listed in `NOTICE.txt`.
